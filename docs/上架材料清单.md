## 二、上架前仍需开发者自行办理

> 以下事项无法由代码材料替代，需在目标商店提交流程中完成或补充。

1. **开发者账号与资质**：按目标应用商店要求注册开发者账号，提交营业执照 / 个人开发者认证等主体材料。
2. **软件著作权登记**：国内软件商店（含微软中国区及国内分发平台）付费上架通常要求软件著作权登记证书；建议提前向版权登记机构申请。
3. **代码签名证书**：当前 exe 未做数字签名；正式上架前建议购买代码签名证书对 exe 签名，避免 SmartScreen / 杀毒软件误报，并满足商店签名要求。
4. **政策文本定稿**：在《隐私政策》《用户协议与免责声明》中填写生效日期、联系邮箱、适用司法辖区，必要时由法务复核；商店后台通常要求上传政策文本或填写托管链接。
5. **商店展示素材**：应用名称、简介、关键词、界面截图（建议含视频列表、格式概览、选项区、日志区）、宣传图与图标；图标需原创，不蹭其他品牌。
6. **版本信息**：填写版本号（当前 1.0.0）、更新记录、适用系统版本（Windows 10/11 64 位）、容量与分级。
7. **合规复核**：不同商店对开源组件披露、隐私权限、免责声明的表单要求不同，提交前对照目标商店开发者政策逐项核对。

## 三、已核查的合规要点

- 软件为本地通用视频合并工具，**不含** DRM/加密破解、去水印、抓流下载等功能。
- 不联网、无广告 SDK、无统计埋点、无第三方分析组件。
- 未捆绑第三方影视、音频、图片等受版权保护素材；应用代码为标准库自写。
- 已内置 GPL 组件披露与源码提供方案；未启用 fdk-aac 等非自由许可组件。
