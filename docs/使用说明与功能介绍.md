# 视频合并工具 · 使用说明与功能介绍

**软件名称**：视频合并工具（多显卡自适应版）
**版本**：1.0.0
**发行形态**：单文件便携版（`视频合并工具_单文件便携版.exe`），免安装、免配置 Python 环境，内置 ffmpeg / ffprobe，双击即可运行
**运行环境**：Windows 10 / 11 64 位
**适用场景**：把多段短视频（如按集拆分的短剧、剧集、剪辑片段、录制片段等）按顺序合并为一个完整视频文件

---

## 一、软件简介

视频合并工具是一款面向本地视频处理的批量合并软件。它以你指定的参考视频格式为基准，把编码、分辨率、帧率、像素格式、音频参数不一致的分段自动归一化后拼接；参数完全一致的分段直接流拷贝、不重新编码，兼顾合并质量与处理速度。

软件优先使用显卡硬件编码加速，显卡或驱动不可用时自动回退 CPU 软件编码，兼容各类独立显卡、核显以及无显卡环境。

## 二、面向大集数短视频合并的核心优点

本工具在设计上专门针对"集数多、单集时长短、来源混杂"的批量合并场景：

### 1. 批量载入，长列表可排序
- 一次可添加几百上千集视频，列表顺序即为最终拼接顺序。
- 支持多选删除、上移、下移、清空，集数顺序错乱时可直接在列表内调整。

### 2. 自动扫描全片，格式分组一目了然
- 添加后后台自动探测每一集的视频编码、分辨率、帧率、像素格式、位深，以及音频编码、Profile、采样率、声道。
- 按格式自动分组列出：每组显示数量、视频格式、音频格式和成员示例，绿色行为当前参考格式。哪些集与基准不一致、不一致在哪一项，打开界面即可看清，无需逐集查看播放器信息。

### 3. 参考格式任选，参数自动跟随
- 默认以第 1 集作为参考格式；在视频列表中点选任意一集，或在概览分组行点选对应格式，即可把该集/该组格式设为参考。
- 切换参考后，编码器、质量 CQ、目标码率、最大码率、Profile、音频码率等选项自动按参考格式回填默认值；自动跟随之后仍可手动修改。

### 4. 能不转码就不转码，大批量合并更快
逐段智能判定三种处理方式：

| 分段情况 | 处理方式 | 速度 |
|---|---|---|
| 视频、音频参数全部一致（含音频 Profile） | 流拷贝重封装，不重编码 | 极快 |
| 视频一致、音频不一致（编码/采样率/声道/Profile 不同） | 视频拷贝，仅音频转 AAC-LC 归一化 | 快 |
| 视频编码/分辨率/帧率/像素格式不一致 | 硬件编码转成参考格式，失败自动软件回退 | 显卡加速 |

所有分段归一化后，用 concat 一次性 `-c copy` 封装成输出文件，**不做第二次整体重编码**，避免大批量素材被重复压缩损失画质。

### 5. 合并前全量预检，坏片集中暴露
- 正式合并前先把全部源文件探测一遍，集中列出无法读取、已损坏的文件，避免合到一半才中断。
- 勾选"跳过无法读取/损坏的视频"后，坏片自动排除，其余集数继续合并；不勾选则遇到坏片即中止并在日志中具名指出。
- 每个分段产物落地后复核视频流、音频流是否完整；临时盘空间不足时给出预警。

### 6. 自动修复常见"混源"音频问题
- 自动对齐音频编码、Profile（如 AAC-LC 与 HE-AACv2 混用）、采样率、声道；混用不同 Profile 的 AAC 直接封装会报错，本工具自动把不一致段的音频重编码为统一的 AAC-LC。
- 源视频没有音轨时，自动补一条与参考采样率、声道一致的等长静音轨，保证拼接不断档。
- 每段只保留第 1 路视频和第 1 路音频，字幕、附件等无关流不会带入输出。

### 7. 大批量过程可控、可排查
- 实时进度条 + 滚动日志，显示当前处理分段、时间进度和结果；中途可随时取消。
- ffmpeg 完整原始 stderr 写入临时目录的 `ffmpeg_full.log`，合并异常时可据此定位到具体分段。
- 勾选"保留中间文件"后，中间分段与日志一并保留，便于复核。

### 8. 多显卡自适应，参数默认推荐
- 编码器跟随参考编码自动选择：H.264 → h264 硬编，HEVC/H.265 → hevc 硬编，AV1 → av1 硬编；QSV 不可用或初始化失败时自动回退 libx264 / libx265 软件编码。
- CQ 按编码给默认值（H.264 23 / HEVC 24 / AV1 28）；音频码率按声道推导（单声道 128k、立体声 192k、多声道 320k）；目标码率按分辨率建议（720p 2500k、1080p 4000k、1440p 6000k、4K 8000k），最大码率默认目标的 1.5 倍。
- 界面整页可滚动，列表、选项、日志全部可见，内容超出窗口高度时右侧自动出现滚动条，支持鼠标滚轮。

## 三、快速上手

1. 双击 `视频合并工具_单文件便携版.exe` 启动（无需安装、无需联网）。
2. 点"添加视频"，按集数顺序选择要合并的视频；用"上移 / 下移"调整顺序。
3. 在"格式分类概览"中核对各组格式；默认第 1 集为参考，如需切换参考，点选对应列表项或概览分组行即可。
4. 在"输出文件"处选择合并后的保存路径与文件名（建议大集数合集先用 `.mkv` 封装，兼容性更好）。
5. 确认下方选项保持默认即可（已自动跟随参考格式）；有需要再手动调整编码器、质量、码率等。
6. 点"开始合并"，等待进度完成；日志区会输出每一步结果，完成后在输出路径得到合并文件。

## 四、选项参数说明

| 参数 | 说明 | 默认 / 可选 |
|---|---|---|
| 编码器 | 跟随参考编码自动选择，也可手动指定 | auto / h264_qsv / hevc_qsv / av1_qsv / libx264 / libx265 |
| 码率模式 | icq 按质量值编码；vbr 按目标码率编码 | icq（质量优先）/ vbr |
| Profile | 默认跟随参考视频 Profile | auto / baseline / main / high / main10 |
| 质量 CQ | 范围 18–32，越小越清晰、文件越大；仅 icq 模式生效 | 按编码自动给默认值 |
| 目标码率 (kbps) | 仅 vbr 模式生效；按分辨率自动建议 | 可手填，如 4000k |
| 最大码率 (kbps) | 仅 vbr 模式生效；默认目标码率的 1.5 倍 | 可手填 |
| Preset | 编码速度与质量的权衡 | veryfast / faster / fast / medium / slow，默认 faster |
| 音频码率 | auto 按声道推导，也可固定 | auto / 128k / 192k / 256k / 320k |
| 保留中间文件 | 勾选后中间分段与日志保留在临时目录，供排查用 | 默认不勾选 |
| 跳过损坏视频 | 勾选后无法读取的坏片自动排除，其余继续合并 | 默认不勾选 |
| 临时目录 | 中间分段与日志的存放位置，默认系统临时目录，可自定义 | 可浏览选择 |
| ffmpeg 路径 | 已内置 ffmpeg / ffprobe；一般无需修改，必要时可手动指定目录 | 内置 |

## 五、支持的输入格式

可导入：`.mp4 .mov .mkv .avi .flv .ts .m4v .wmv .webm .mpg .mpeg` 等常见容器；输出封装建议 `.mp4` 或 `.mkv`（HEVC / 10bit / 特殊音频素材优先用 `.mkv`）。

## 六、常见问题

- **日志提示 QSV 失败后自动 software**：当前环境显卡未识别或驱动不可用，转码自动改走 CPU 软件编码，功能不受影响。
- **某集解析失败被中止**：日志会给出具体文件名，先用播放器或 ffprobe 单独检查该文件是否损坏、能否正常播放；勾选"跳过损坏视频"可排除坏片继续。
- **输出 MP4 时 HEVC 报错**：改用 `.mkv` 输出，或在界面把编码器选 `h264_qsv` / `libx264`。
- **10bit (HDR) 视频**：自动保持 p010 像素格式，HEVC Main10 对应 `hevc_qsv`，无需手动设置。
- **合并后时长只算到第一段**：本工具已对拷贝段做重封装与时间戳修正，正常不会出现；若仍异常，请保留中间文件并查看临时目录 `ffmpeg_full.log` 反馈具体分段。
- **临时盘空间不足**：大集数合集建议把"临时目录"改到剩余空间充足的磁盘后再合并。

## 七、大集数合并建议

1. 合并前先用概览确认各组格式：参考集应选画质、分辨率最符合最终成品要求的那一集。
2. 来源混杂、坏片较多的批次，先勾选"跳过损坏视频"跑一遍预检，再单独处理被剔除的文件。
3. 长合集优先输出 `.mkv`；需要在老设备或特定平台播放时，再按平台要求转 `.mp4`。
4. 中间文件会占用与合集接近的临时空间，确保临时目录所在磁盘留有足够余量；合并完成后临时文件自动清理（勾选保留中间文件除外）。
5. 10bit、多声道、不同来源混剪的素材，保持默认自动归一化即可，不要手动强行指定与参考不符的 Profile。
