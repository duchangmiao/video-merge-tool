## 二、FFmpeg 内置的其他开源库

本次内置 FFmpeg 构建还链接了以下开源库，各库保留其原始许可证（BSD、MIT、ISC、LGPL、zlib、FTL、MPL-2.0 等），版权归原作者所有：

- 视频编解码：libvpx、SVT-AV1、rav1e、dav1d、libaom、openh264、openjpeg、libjxl
- 音频编解码：LAME（mp3lame）、libopus、libvorbis、Theora、two-lame、opencore-amrnb / amrwb、soxr（重采样）
- 图形/文本：freetype、harfbuzz、fontconfig、libass、libfribidi、lcms2、librsvg、libwebp
- 压缩/压缩支持：zlib、liblzma、libsnappy、libxml2、libgmp
- 网络/协议：libcurl、libssh、libsrt、librist
- 其他：libvmaf、libplacebo、libSDL2 等

完整编译配置见本说明附录 A。各库的源码与许可证可在 FFmpeg 官方源码包及对应项目仓库获取。

## 三、GPL 源码提供义务

1. **本应用程序源码**：与本软件对应的应用程序源代码（`app.py`、`merge_core.py`）已随本仓库提供；如需重新打包，可使用随附源码配合 PyInstaller 构建。
2. **第三方 GPL 组件源码**：FFmpeg、x264、x265 的完整源码可从其官方仓库下载（地址见上表与附录 A）。如需获取与本二进制完全对应的第三方组件源码，开发者可在收到书面请求后三年内提供完整对应源码或获取方式，联系方式见《隐私政策》。
3. 本软件中的应用程序代码为使用 Python 标准库（含 Tkinter）自行编写，未复制其他项目的专有代码片段。

## 附录 A：内置 FFmpeg 编译配置（摘要）

`--enable-gpl --enable-version3`，并启用 libx264、libx265、libvpx、SVT-AV1、rav1e、dav1d、libaom、mp3lame、opus、vorbis、theora、webp、zlib、libxml2、libssh、libsrt 等组件；未启用 libfdk-aac 等非自由许可组件。完整 `--version` 配置以实际内置构建为准。
