# 源码获取说明（GPL 对应源码提供）

## 一、本应用程序源码

本仓库已包含与本软件对应的应用程序源代码：

| 文件 | 说明 |
|---|---|
| `app.py` | Tkinter 图形界面源码（文件列表、格式概览、参考格式、选项、进度与日志） |
| `merge_core.py` | 合并核心源码（探针分析、分段策略、QSV/软件回退、concat 封装、预检与坏片处理） |
| `requirements.txt` | 依赖说明（运行仅用 Python 标准库；打包需 PyInstaller） |
| `run.bat` / `build.bat` | 开发态启动脚本 / PyInstaller 打包脚本 |
| `README.md` | 项目说明 |

源码可在 Python 3.9+ 环境下直接运行调试；重新打包时按 `build.bat` 说明执行。内置 ffmpeg / ffprobe 二进制不随源码仓库分发，开发调试时可按 `README.md` 指引放置。
