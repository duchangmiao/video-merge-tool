# 隐私政策

**适用产品**：视频合并工具（多显卡自适应版），单文件便携版
**生效日期**：____年____月____日（上架前填写实际生效日期）

## 一、我们如何处理你的视频文件

1. 本软件是本地桌面工具，所有视频的读取、解析、转码、合并与输出过程均在你的电脑本机完成。
2. 软件**不会**把你添加的视频文件、输出文件、文件路径、文件名或处理日志上传到任何服务器，不进行远程分析或云端处理。
3. 合并过程中产生的中间分段、临时文件和日志仅保存在你本机指定的临时目录（默认为系统临时目录）；未勾选"保留中间文件"时，任务结束后自动清理。

## 二、数据收集与网络行为

1. 本软件不含广告 SDK、统计埋点、崩溃上报、设备标识采集或第三方分析组件。
2. 软件运行过程中不主动发起联网请求；内置的 ffmpeg / ffprobe 仅在本地被调用执行音视频处理。
3. 我们不收集、不存储、不共享你的个人身份信息、文件内容或使用记录。

## 三、本地日志

1. 软件界面日志与可选的 `ffmpeg_full.log` 仅保存在本机临时目录，用于排查合并问题；不会被自动发送。
2. 如你向技术支持反馈问题并主动提供日志或截图，我们仅用于定位该次问题。

## 四、第三方组件

软件内置并使用了开源第三方组件（FFmpeg、x264、x265、Python 运行时、Tcl/Tk 界面库等），其许可证与版权声明见同目录《开源许可与第三方组件说明》及 `LICENSES/` 文件夹。这些组件同样在本机运行，不涉及向第三方传输你的文件。

## 五、你的权利

- 你可以随时通过不安装、删除本软件的方式停止使用；删除程序文件及本机临时目录即可清除全部本地处理痕迹。

本政策如随软件版本调整而更新，将在软件说明或发布页同步公示；更新后的政策自公示之日起生效。
